# LinkedIn Organic Content Strategy for B2B SaaS

## Topic Selection

For this project, I chose **LinkedIn organic content strategy for B2B SaaS**.

I selected this topic because LinkedIn is a primary growth channel for B2B companies, especially in SaaS, where personal branding and content can directly drive inbound leads without relying on paid ads or cold outreach.

---

## Data Collection Approach

After selecting the creators, I collected their recent LinkedIn posts manually.

I then structured the data into an API-like format, including:

* Post metadata (date, URL)
* Content breakdown (hook, summary, key points)
* Content type and tone
* Engagement strategy and pattern tags

This structure allows for deeper analysis of content patterns and can be used to build a repeatable LinkedIn content playbook for B2B SaaS.
